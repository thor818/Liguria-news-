# Poster Live Riviera — Collezione N° 1

Poster in stile vintage, formato 50 × 70 cm. Liguria: Genova, Portofino, Camogli, Sanremo. Côte d'Azur: Nice, Menton, Monaco.

- `stampa/` — PDF vettoriali 50 × 70 cm per la tipografia.
- `png/` — immagini ad alta risoluzione (1000 × 1400) per web, social e prove.
- `svg/` — file sorgente modificabili (Illustrator, Inkscape, Figma).
- `genera.py` — script che disegna i poster; per un nuovo poster si aggiunge una funzione e si rilancia `python3 genera.py`.
- `galleria.html` — pagina con tutta la collezione.

Font: Bebas Neue e Josefin Sans (Google Fonts, licenza libera anche per uso commerciale).
I disegni sono originali, creati per Live Riviera.
