# Poster Live Riviera — collezione vintage

Poster 50 × 70 cm nello stile delle vecchie affiches della Riviera. Ogni città ha uno stile diverso:

| N° | Città | Stile |
|---|---|---|
| 01 | Genova | Art déco anni '30 — la Lanterna, "La Superba" |
| 02 | Portofino | Rétro anni '60 — signora in motoscafo di mogano |
| 03 | Camogli | Acquerello — case alte e ombrelloni a righe |
| 04 | Sanremo | Rétro anni '60 — ciclista con cesto di fiori |
| 05 | Nice | Acquerello — sedia blu sulla Baie des Anges |
| 06 | Menton | Linoleografia a tre colori — limoni |
| 07 | Monaco | Grand Prix anni '50 — monoposto rossa |

- `vintage/stampa/` — PDF 50 × 70 cm e JPG (3000 × 4200 px) per la tipografia.
- `vintage/svg/` — file sorgente modificabili.
- `vintage/web/` — immagini leggere per sito e social.
- `vintage.py` — script che disegna i poster (`python3 vintage.py`).
- `galleria.html` — pagina con tutta la collezione.

Disegni originali creati per Live Riviera. Font Google Fonts (licenza libera, anche uso commerciale).
